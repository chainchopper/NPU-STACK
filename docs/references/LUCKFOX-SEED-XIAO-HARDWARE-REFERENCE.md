## MCP2221 Bridge
- Microchip MCP2221 USB-I2C/UART Combo (04D8:00DD)
- Used as USB bridge for GPS radio module
- Exposes COM14 serial port on Windows
- NPU-STACK should communicate via serial terminal (WebSocket bridge)
